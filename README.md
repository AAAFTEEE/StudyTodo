# StudyTodo — 作业/学习待办管理器 v4

一个基于 **C++ + Win32** 的图形桌面作业管理工具（纯原生 API，无第三方依赖，仅需 MinGW 编译）。

从 v1 的控制台版一路演进到 v4 的图形桌面版：科目分组、任务打卡、进度统计、番茄钟，全部在一个清爽的窗口里完成。

---

## 功能特性

- **图形界面**：左侧科目树 + 右侧任务列表 + 底部进度条/状态栏，现代视觉样式（圆角、平滑）
- **直接编辑**：单击状态列打勾/取消；双击任务文字就地编辑；双击学科列下拉换科目
- **学科配色**：不同科目用不同背景色区分，一眼看清
- **视图过滤**：全部任务 / 未完成 / 已完成 / 按科目，支持关键词搜索
- **列排序**：点表头按学科排序
- **多作业单**：新建、打开、另存、删除，数据存为文本文件
- **工具**：番茄钟（25 分钟专注倒计时）、进度统计面板
- **主题**：浅色 / 深色一键切换
- **自动保存**：每次改动自动写入文件
- **兼容**：可读取 v2 时代生成的 GBK 数据文件

## 目录结构

```
StudyTodo/
├── src/
│   └── studytodo_v4.cpp      # 主程序源码（单文件）
├── res/
│   ├── app.manifest          # 视觉样式清单（ComCtl32 v6）
│   └── app.rc                # 资源脚本（把 manifest 编入 exe）
├── build/
│   └── app_res.o             # 编译中间产物（可删，可重建）
├── homework/                 # 作业单数据目录（文本文件，GBK）
├── build.bat                 # 一键构建脚本
├── studytodo_v4.exe          # 构建产物（双击运行）
└── README.md
```

## 编译

依赖：**MinGW-w64**（`g++`、`windres` 需在 PATH 中）。

**一键构建**：双击 `build.bat`，或在项目根目录执行：

```bat
build.bat
```

**手动构建**：

```bat
windres res\app.rc -O coff -o build\app_res.o
g++ -std=c++17 -municode -O2 -mwindows src\studytodo_v4.cpp build\app_res.o -o studytodo_v4.exe -lcomctl32 -lcomdlg32 -lgdi32 -luser32
```

## 使用

1. 双击 `studytodo_v4.exe` 运行（会自动加载 `homework\` 里最近保存的作业单）。
2. 左侧科目树切换视图；右侧列表操作任务。
3. 常用操作：
   - **单击状态列** = 打勾 / 取消完成
   - **双击任务文字** = 就地编辑任务内容（回车确认，Esc 取消）
   - **双击学科列** = 下拉选择，把任务移到另一个科目
   - **右键任务** = 快捷菜单（标记完成 / 编辑 / 删除 / 新增）
   - **右键 / 双击** 更多功能在顶部菜单与工具栏
4. 数据自动保存到 `homework\*.txt`。

### 数据文件格式（兼容 v2）

```
# 科目名
- 未完成任务
+ 已完成任务
```

（v3/v4 扩展：任务行末尾可用 `\t@@KEY=VAL@@` 携带优先级/截止日期/标签等附加属性，纯文本任务仍与 v2 完全兼容。）

## 自检模式

不启动界面，验证数据读取与写回：

```bat
studytodo_v4.exe --selftest
```

## 版本历史

- **v1**：控制台版，科目 + 作业录入与打卡
- **v2**：控制台版增强（增删改查、进度条、多套作业单、文件存取）
- **v3**：升级为 Win32 图形桌面版（科目树、任务列表、就地编辑、学科配色、番茄钟、统计、深色主题）
- **v4**：整理为独立工程（源码 / 资源 / 构建脚本 / 文档分离，一键构建）
